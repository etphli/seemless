# Seemless 0.2.0

The first downloadable release for Apple Silicon Macs running macOS 14 or later.

- Refined graphite and light appearances, violet selection, compact controls, and clearer panel grouping.
- App-first command bar with custom standard and Caps Lock Hyper shortcuts.
- Installed app discovery, favourite apps, and open/focus/return switching.
- Local text, link, and image clipboard history with search, pinning, and seven-day expiry.
- Cached command results and image thumbnails to avoid repeated work during navigation.
- Signed GitHub release updates through Sparkle. An update button appears in Settings and the menu bar when a compatible newer release exists. Updates download, verify, install, and relaunch through the native updater.

Clipboard recording and Caps Lock Hyper start off. Accessibility is needed for precise window return, direct paste, and Caps Lock Hyper. Those physical workflows still need manual testing on your Mac.

This release is ad-hoc code signed and has signed update archives. It is not Apple notarized. On a Mac that quarantines the initial download, open it through Privacy & Security or use the documented local installation command after verifying the downloaded artifact.
