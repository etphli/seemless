# Seemless 0.2.1

- Treat Sparkle's “no newer update” completion as a normal result, avoiding a false failure in runtime logs.
- Install into the user's Applications folder when the system Applications folder requires administrator access. The installer still verifies the bundle, preserves an existing Seemless installation, clears only its quarantine attribute, and checks the launched process path.

Includes the refined native interface and signed GitHub updater introduced in 0.2.0. Apple Silicon, macOS 14 or later. The app is locally code signed and has signed update packages; it is not Apple notarized. Accessibility-dependent keyboard and window workflows still need manual testing.
